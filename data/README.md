## Dataset Description

| Item | Detail |
|------|--------|
| Rows | ~2.15 million customers |
| Columns | 19 |
| Target | `CHURN` (0 = stayed, 1 = churned) |
| Source | Expresso Telecom — Mauritania & Senegal |
| Period | 6 months of customer behaviour |

### Key Features

| Column | Description |
|--------|-------------|
| `REGION` | Customer's geographical region (14 regions in Senegal) |
| `TENURE` | Duration as a customer (banded in 3-month intervals) |
| `MONTANT` | Total top-up amount |
| `FREQUENCE_RECH` | Number of times the customer recharged |
| `REVENUE` | Monthly revenue generated by the customer |
| `ARPU_SEGMENT` | Average revenue per user (income segment) |
| `FREQUENCE` | Number of times the customer used the network |
| `DATA_VOLUME` | Volume of data consumed |
| `ON_NET` | Calls made to Expresso network numbers |
| `ORANGE` | Calls made to Orange network |
| `TIGO` | Calls made to Tigo network |
| `REGULARITY` | Number of active days in a 90-day period |
| `FREQ_TOP_PACK` | Frequency of top pack purchases |
| `CHURN` | Target variable — 1 = churned, 0 = stayed |
